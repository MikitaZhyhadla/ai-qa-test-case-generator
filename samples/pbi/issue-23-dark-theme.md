# PBI: Switch between light and dark theme in Notely

## Context

Product: Notely, a fictional note-taking web app. Today the app has only a light theme.

## User story

As a Notely user, I want to switch between a light and a dark theme, so that I can work comfortably at night.

## Acceptance criteria

1. The "Settings" page has a "Theme" option with the values "Light" and "Dark"; "Light" is selected by default.
2. Selecting a value applies the theme to all pages immediately, without reloading the page.
3. The selected theme is saved for the user account and applied after the next login on any device.
4. Text and buttons remain readable in both themes.

## Out of scope

- Following the operating system theme automatically
